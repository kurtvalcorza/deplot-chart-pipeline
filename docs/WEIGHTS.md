# Weight provenance and DIMER hosting

- Upstream: `google/deplot`
- Immutable revision: `6e76d62430da16986be3426bae32301fb9115397` (the Hub's `main` resolved to this commit on 2026-09-14)
- Weight format: SafeTensors (`model.safetensors`, 1,129,177,976 bytes, float32). The upstream repository also hosts `pytorch_model.bin` (1,129,238,081 bytes), a pickle checkpoint that DIMER does not accept and this pipeline neither lists nor loads.
- Manifest: `weights/deplot/dimer-base-manifest.json` (8 files: `README.md`, `config.json`, `model.safetensors`, `preprocessor_config.json`, `special_tokens_map.json`, `spiece.model`, `tokenizer.json`, `tokenizer_config.json`; 1,133,308,796 bytes total, per-file SHA-256)
- Upstream weight license: Apache-2.0 (the checkpoint's `README.md` front matter and the Hub's licence tag)
- DIMER hosting: Apache-2.0 permits use, modification, distribution, and commercial use subject to preservation of the licence and notices. The Git repository does not vendor the checkpoint (`weights/**/*.safetensors` is git-ignored); DIMER may mirror the pinned snapshot in its model store under the upstream license.
- Fresh clone: `stage_missing_files(allow_download=True)` fetches only the manifest-listed files absent on disk, at the pinned revision, into the snapshot directory; `verify_snapshot()` then checks every file before any load. `weights/**` is marked `-text` in `.gitattributes` so Windows `core.autocrlf` cannot rewrite the committed small files and break their digests.
- Loader trust boundary: Transformers `Pix2StructForConditionalGeneration` / `Pix2StructProcessor` with `trust_remote_code=False`, `local_files_only=True` from the verified directory; the tokenizer (`spiece.model`, `tokenizer.json`) comes from the same snapshot; nothing model-related is fetched at construction (the smoke run loaded and ran with `HF_HUB_OFFLINE=1`).
- **Header font, deliberately not the upstream default:** the VQA image processor renders the fixed instruction above the chart and, unless given a font, downloads `ybelkada/fonts/Arial.TTF` from the Hub at *inference* time — an unpinned, unlisted download of a proprietary font. `header_font_bytes()` supplies Pillow's bundled Aileron Regular subset (CC0, covers printable ASCII) as `font_bytes` instead, and the loader calls the image processor directly because `Pix2StructProcessor.__call__` drops that keyword. Header glyph shapes therefore differ from the upstream fine-tuning renders (Arial); the effect on answers was not measured beyond the smoke run's 9/10 cells and exact title.
- **Adapters are not upstream weights.** `DePlotPipeline.save_artifact` writes only the tensors `adapt` trained (the decoder's last *k* blocks plus its final layer norm, in float32; the untied `lm_head`, every embedding and the image encoder stay frozen) as `adapter.safetensors` beside a `manifest.json` that names the base model id, revision and the SHA-256 of the base `model.safetensors`; `from_artifact` refuses an adapter whose manifest names a different base, whose file digest drifts, whose tensor set differs from the recorded configuration, or which carries a tensor outside `decoder.`.
- **Tutorial corpus (not vendored):** `docling-project/SynthChartNet` at the immutable dataset revision `b913ef98a3d45f6136465963ddc71a7a6b0e1728`, file `train-00000-of-00135.parquet` (515.8 MB; its exact byte size and SHA-256 `1d6cf578…b209e7` are pinned in `samples.py`; 14,568 charts: bar 6,491, pie 6,665, stacked bar 1,333, line 79), pinned in `src/deplot_chart_pipeline/samples.py` by `tools/pin_corpus.py` and downloaded at run time into the git-ignored `weights/synthchartnet/`.
